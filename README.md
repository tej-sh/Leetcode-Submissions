# LeetCode Submissions

An active collection of LeetCode problem solutions written primarily in Python.

Each problem is organized in its own directory using the problem number and title.

## Topics Covered

- Arrays
- Strings
- Linked Lists
- Trees
- Graphs
- Dynamic Programming
- Recursion
- Sorting and Searching
- SQL
